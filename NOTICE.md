## Estedad variable font provenance

`assets/estedad/Estedad-Variable.woff2` is the unmodified official Estedad 7.3 variable webfont from Amin Abedi's repository. It replaces nine static font faces in the runtime and covers weights 100–900. The additional KSHD axis uses the font default.

- Source: https://github.com/aminabedi68/Estedad/blob/6bf2cb6d3e4be18a28225746de75c10773acc784/fonts/webfonts/variable/Estedad%5BKSHD%2Cwght%5D.woff2
- SHA-256: `55910be66020e77f9ff5bf9164e9afc0d9c01e7e186b63808e0cd14f5f87f031`
- Original upstream filename: `Estedad[KSHD,wght].woff2`. Only the local filename changed.
